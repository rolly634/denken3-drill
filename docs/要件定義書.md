# 電験三種 短答ドリル 要件定義書

対象：v1.15.1（2026-11-26 時点）
ファイル形式の細かい決まりは [データ形式.md](データ形式.md)、過去問の作り方は [../tools/README.md](../tools/README.md) を見る。

## 1. 目的と前提

- 電験三種（理論・電力・機械・法規）の短答式を、スマホで毎日少しずつ演習するための**個人用**アプリ。
- 使う人は 1 人（作者）。主な端末は Android の Chrome。ホーム画面に追加して PWA として使う。
- **お金がかからないこと**を優先する。AI の API やサーバーは使わない。問題づくりや質問は Claude アプリ（Pro プランの範囲）で行う。
- 過去問は**個人の学習用**。公開リポジトリには入れない。

## 2. 全体の構成とデータの流れ

```
過去問 PDF ──(tools/ で変換・Claude のチャットで作業)──▶ 作業フォルダ（リポジトリの外）
                                                        │ tools/make_pack.py
                                                        ▼
                                  Google Drive「denken3-drill」フォルダ（非公開）
                                    ・まとめパック（pack-v1）
                                    ・バックアップ（backup-v1）
                                                        │ アプリの「Drive を見る」
                                                        ▼
GitHub Pages（アプリ本体だけ）──▶ 端末のブラウザ（IndexedDB に問題・記録を保存）
                                                        │ 「Drive に保存」／書き出す
                                                        ▼
                                              Drive にバックアップ
```

| 置き場所 | 中身 | 公開 |
|---|---|---|
| GitHub `rolly634/denken3-drill` | アプリ本体、文書、テスト、変換ツールの共通部分 | 公開 |
| 非公開リポジトリ（予定） | 回ごとの作成スクリプト（問題文・解答を含む） | 非公開 |
| Google Drive `denken3-drill` | まとめパック、バックアップ | 非公開・共有なし |
| 端末（IndexedDB） | 取り込んだ問題、学習記録 | 端末の中だけ |

## 3. 機能要件

### 3.1 演習（4 択・空欄補充）

| 機能 | 要件 |
|---|---|
| 問題一覧 | 科目 → 単元で並べる。タップした問題から順に出題 |
| 続きから | 中断した演習を同じ問題から再開 |
| 苦手克服 | 1 つでも空欄を間違えた問題が入る。**2 回連続正解**で外れる |
| ブックマーク | ☆ で付け外し。問題ファイルの `bookmark: true` は初回取り込み時だけ付ける |
| ランダム演習 | 選んだ科目から区切りなく出題 |
| アウトプット | 選択肢を選んで採点。空欄 1 つはタップで即採点、2 つ以上は下のパネルで選んで「採点する」 |
| インプット | 赤シート式。空欄を隠してタップで表示。正誤は記録しない |
| 共通 | 選択肢は毎回シャッフル。前へ戻れる。数式は KaTeX、図は SVG（タップで拡大、ダークモード対応） |

### 3.2 公式カード

- 表（状況）を見て 4 つの式から選ぶ → 裏（公式名・式・記号の意味と単位・適用条件）。
- 1 回でも解いたカードは「学習済み」。シャッフルは学習済みカードを区切りなく出す。
- 記録はカードごとの正誤だけ（演習の苦手克服とは別）。

### 3.3 計算練習

- テンプレートから**開くたびに数値を変えて**出題し、答えはアプリが計算する。
- 途中式を 1 段ずつ判定（相対誤差 1% 以内）。間違えるとヒントを最大 3 段階、それでも外れたら答えを見せて次へ。選択式の段もある。
- 入力欄は電卓を兼ねる（√・π・²・括弧・Ans・三角関数（度）・k/M/m/μ・×10ⁿ）。
- 答えは小数に加えて、分数・√・π のきれいな形があれば並べて表示。
- 終わったら値入りの解説と、「Claude に聞く文をコピー」（API を使わず、Claude アプリに貼って質問する）。
- 過去問の途中式は、元の問題の図を `figuresFrom` で参照する（図を二重に持たない）。

### 3.4 問題の取り込み

- 設定 → 「ファイルを選ぶ」「貼り付け」、または Google Drive から。
- 読める形式：まとめパック `pack-v1`、問題 `v1`、公式カード `cards-v1`、計算練習 `calc-v1`。
- 同じ `id` は上書き（学習記録は残す）。取り込む前に形式を確かめ、だめなものは件数と理由を出す。

### 3.5 保存とバックアップ

- 問題・学習記録はすべて端末の IndexedDB に保存（上限は数百 MB 以上）。ブラウザに「自動で消さない」ようお願いする（`storage.persist`）。
- 学習記録は 150ms まとめて書く。閉じる直前は localStorage に控え、次に開いたときに書き直す（すぐ閉じても消えない）。
- 別のタブで保存されたら読み込み直す。
- 前の版（localStorage）のデータは初回に自動で引っ越す。
- バックアップ（`backup-v1`）は「Drive に保存」「共有して保存」「書き出す」で作り、「読み込む」で丸ごと置き換える。最後にバックアップした日を表示する。
- リセット：「学習記録だけ消す」「すべて消す」。

### 3.6 Google Drive 連携

- Google でログイン（Google Identity Services。トークンは約 1 時間、保存しない）。
- 権限は `drive.readonly`（フォルダを読む）と `drive.file`（バックアップを書く）だけ。
- `denken3-drill` フォルダの `.json` を一覧し、種類（パック・問題・バックアップ）を表示。前に取り込んだパックより新しいものに「新しい版」を付ける。
- タップで取り込み（バックアップは置き換えの確認を出す）。「Drive に保存」で同じフォルダにバックアップを作る。
- Google Cloud プロジェクト `326647858563`。OAuth 同意画面は「テスト」、テストユーザーは自分だけ。

### 3.7 アプリの更新

- `sw.js` の `VERSION` を上げると端末のキャッシュが入れかわる。戻ってきたときにも更新を確かめる。
- うまく変わらないときは設定 → 「アプリを最新にする」。

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| オフライン | 一度開けば、取り込み済みの問題はネットなしで使える（Drive 連携だけネットが必要） |
| 依存 | ビルドなしの HTML / CSS / JS。KaTeX は同梱。外部 CDN を使わない |
| 費用 | 0 円（GitHub Pages、Google Drive の無料枠、Claude アプリの Pro プラン内） |
| 秘密情報 | クライアントシークレット・API キーは使わない・置かない。クライアント ID は公開してよい |
| 過去問の扱い | 公開リポジトリ・公開の場所に置かない。Drive は共有しない |
| 見た目 | スマホ縦向き前提。ダークモード対応。図はテーマの色に合わせる |
| 安全 | 取り込んだ SVG は表示するときに `<script>`・`on…` 属性・外部 URL・`<style>` を取り除く |

## 5. 作らないこと

- AI が答える機能（API 料金がかかるため。前にあった「ギャル先生」は v1.15 で削除）。
- サーバー、アカウント、複数端末の自動同期（必要なら Drive のバックアップで移す）。
- 問題の共有・公開、ランキング。
- アプリの中での問題の編集（問題はチャットとツールで作り、ファイルで入れる）。
- 古い取り込み形式の廃止（読めるのは残す。新しく作るのはパックとバックアップだけ）。

## 6. 決まりごと

| 項目 | 決まり |
|---|---|
| 過去問の id | 問題 `<回>-<問番号2桁>`（例 `r7s-05`）、途中式 `<回>-<問番号><(a)(b)>-calc` |
| 回のコード | `h25`〜`r3`、上期 `f`・下期 `s`（例 `r4f`＝R4上期） |
| 並び順 | `order = 分野 × 10000 + 回 × 100 + 問番号`（分野別に並ぶ）。分野と回の順は `tools/fields.py` |
| ドリル・カード | `riron-008`、`card-riron-010` のように科目名＋番号 |
| オリジナル計算 | `c-…`（例 `c-pf-1`） |
| パックの大きさ | 1 ファイル 3.0MB まで（Claude のチャットから Drive に 1 回で送れる量）。回の途中では分けない |
| バージョン | 画面やデータが変わったら `app.js` の `APP_VERSION` と `sw.js` の `VERSION` を一緒に上げる |
| 変更の入れ方 | ブランチ → プルリクエスト → `tests/run.py` が全部 OK → マージ |
