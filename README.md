# 電験三種 短答ドリル

電験三種の短答式問題を 4 択で演習する Web アプリ（PWA）です。
Android の Chrome で開き、メニューの「ホーム画面に追加」でアプリとして使えます。一度開けばオフラインでも動きます。

**公開 URL:** https://rolly634.github.io/denken3-drill/

## しくみ

- このリポジトリにはアプリ本体だけが入っています。**問題データは入っていません。**
- 問題は JSON ファイルとして端末に取り込みます（設定 → 問題を取り込む）。
- 問題・学習記録・ブックマークはすべて端末のブラウザ（IndexedDB）に保存されます。容量の上限は端末の空きに応じて数百 MB 以上あります。
  前の版（localStorage）のデータは、新しい版を初めて開いたときに自動で引っ越します。
- 問題は Google Drive の `denken3-drill` フォルダに置いたまとめパックから、設定 → Google Drive で取り込めます。
- ブラウザのデータを消すと失われるので、設定 → Google Drive →「Drive に保存」でときどきバックアップしてください。

## 画面

| メニュー | 内容 |
|---|---|
| 続きから | 前回の演習を中断した問題から再開 |
| 問題一覧 | 科目・単元ごとに一覧。タップした問題から順に出題 |
| 苦手克服 | 間違えた問題（空欄が1つでも誤答なら対象）。2回連続正解で外れる |
| ブックマーク | ☆ を付けた問題。問題画面・解説画面のどちらからでも付けられる |
| ランダム演習 | 選んだ科目からランダムに、区切りなく出題 |
| 計算練習 | 数字が毎回変わる計算問題を、途中式 1 段ずつ・電卓つきで。下の「計算練習」を参照 |

アウトプットでは、空欄が1つの問題（「〜の式は？」のような文中に空欄がない問題も含む）は、公式カードと同じく問題文の下に選択肢を並べ、タップするとそのまま採点する。空欄が2つ以上の問題は、問題を開くと1つ目の空欄の選択肢（2択／4択）が画面下のパネルに出ている。ほかの空欄はタップで切り替え。選ぶと次の未回答の空欄へ自動で移り、すべて埋まるとパネルが閉じて「採点する」。採点後に空欄をタップすると、その空欄の選択肢と正誤を確認できる。

出題画面の上部で **アウトプット**（選択肢を選んで採点）と **インプット**（赤シート式の暗記）を切り替えられる。最後に使ったモードを覚えておく。

- インプットでは空欄が紺のシートで隠れ（表示すると黄色のマーカー）、タップで答えを表示／もう一度タップで隠す。複数の空欄は下部ツールバーの「すべて表示／すべて隠す」でまとめて切り替え。
- 文中に空欄がない解答欄（「〜の式は？」など）は、問題の下に答えの欄を置く。
- 問題・答え・解説を1画面に表示し、ツールバーの「次へ」で次の問題へ。正誤は記録しない。
- どちらのモードでも、ツールバーの「前へ」で前の問題に戻れる（アウトプットでは解き直しになる）。

## 計算練習

トップの「計算練習」から使う。AI も API キーも使わずに、紙とペンなしで計算問題を練習するモード。

- **数字ガチャ**：問題は「テンプレート」になっていて、開くたびに数値が変わる。答えもアプリが計算するので、同じ問題を何度でも違う数字で練習できる（右上のサイコロ、または「同じ問題を別の数字で」）。
- **途中式ステップ**：計算を小分けにして、1 段ずつ数値を入れて判定する（相対誤差 1% 以内で正解）。間違えるとヒントが最大 3 段階で出て、それでも外れたら答えを見せて次の段へ進む。選択式の段（進み／遅れなど）もある。
- **電験キーパッド**：入力欄がそのまま電卓。`40÷0.8` や `√3×200` のような式のまま判定できる。√・π・²・括弧・Ans、「fn」で sin / cos / tan（角度は度）、√3、2π、k・M・m・μ、×10ⁿ。「＝」で計算して履歴に残し、履歴をタップすると値を入れられる。
- 答えは小数と、計算の中で自然に出てくる分数・√・π の形を並べて表示する（例：5.77（$\tfrac{10}{\sqrt3}$）、159（$\tfrac{500}{\pi}$））。電卓のプレビューも同じ。sin・cos を使う値など、きれいな形にならないものは小数だけ。
- 終わったら解説（値入り）と、「Claude に聞く文をコピー」（問題と自分の途中式をまとめた質問文。Claude アプリに貼れば Pro プランの範囲で質問できる）。
- 記録はほかのモードとは別に持つ。一覧の「おまかせ」は未挑戦→前回ミス→その他の順に出す。

## 公式カード

トップの「公式カード」から使う。表（状況・条件）を見て4つの式から選び、選ぶと裏（公式名・式・各文字の意味と単位・適用条件）が開く。

- 一覧のカードをタップすると、そこから順に出題。1回でも解いたカードが「学習済み」になる。
- 「シャッフル」は学習済みのカードを区切りなくランダムに出し続ける（一巡したら並べ替えて続ける）。科目チップで範囲を絞れる。
- 記録はカードごとの正誤（回数・直近の○×）だけ。演習の正答率・苦手克服とは別。バックアップには含まれる。

## 開発メモ

- 依存なしの素の HTML / CSS / JS。数式表示に KaTeX（`vendor/katex`）を同梱。
- 計算練習は `calc.js`、Google Drive 連携は `drive.js`（どちらも `app.js` のあとに読み込み、`app.js` のヘルパーとルーターを使う）。
- `app.js` の `APP_VERSION` と `sw.js` の `VERSION` を一緒に上げると、端末側のキャッシュが更新される。
- テスト：`pip install playwright && python3 -m playwright install chromium` のあと `python3 tests/run.py`。データは `tests/fixtures.py` の作りものだけを使う。
- **過去問のデータ（問題文・解答・図）はこのリポジトリに入れない。** 作業フォルダはリポジトリの外に置く（`tools/README.md`）。
